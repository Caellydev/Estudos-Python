#PYTHON_AULAS

Repositório com exercícios e estudos práticos de Python desenvolvidos durante o curso de Computer Engineering na UNIVESP, com foco em lógica de programação, estruturas de dados e análise de dados com pandas.

🎯 Conteúdo
Fundamentos de Python: loops, funções, tuplas, pilhas/filas, escopo de variáveis (local/global), f-strings
Análise de dados com pandas: leitura de CSV (local e via URL), tratamento de encoding, limpeza de dados, agrupamento e contagem (value_counts(), groupby())
Visualização de dados: gráficos com matplotlib
Datasets utilizados: dados públicos abertos (ex: escolas municipais de Belo Horizonte, consumo de álcool por país)


🛠️ Tecnologias:

Python 3;

pandas;

matplotlib.
